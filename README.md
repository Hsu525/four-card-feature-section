The main goal was to recreate the provided design as closely as possible while practicing responsive layouts with Flexbox and CSS Grid.

### What I learned

This project helped me improve my understanding of responsive CSS layouts.

In particular, I practiced:

Building a mobile-first layout with Flexbox
Using CSS Grid for complex desktop layouts
Working with grid-template-areas
Creating nested layouts with Flexbox and Grid
Keeping card widths consistent across different screen sizes
Using justify-self and align-self
Creating responsive spacing and typography
Using CSS custom properties for colors
Structuring CSS into reusable component styles

One of the most useful things I learned was that Grid only controls its direct children. Because the cards were inside a .card-container, I used a separate Grid for the card layout while the outer container handled the overall layout.
